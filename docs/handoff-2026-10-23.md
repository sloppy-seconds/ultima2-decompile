## Standing traps — read before trusting anything

Carried forward, plus today's. **Today's are marked NEW.**

* **Memory reads pause the CPU**; keys sent in that window are silently lost. Settle
  0.5–1 s after a read before injecting a key, and verify every step. Today this moved a
  monster between a read and a screenshot and produced an apparent rendering mismatch.
* **`monitor breakCsIp` parses hex while `/api/status` reports decimal.** `reject_trap.py`
  converts in one asserted place.
* **`ExecutedInstructions` is a deduplicated address set, not a trace.** `blocks` are
  *discovered*, not executed.
* **`DS:20` is scratch, not a reject signal.**
* **Never edit a file with a script; never heredoc a non-trivial script.** `str.replace`
  that misses returns the string unchanged and exits 0.
* **In `asm/`, only the filename and `#` lines may change — labels are body.** CP0 md5s
  every non-`#` line. Today's two `asm/` header edits were verified with
  `assemble_clean.sh` in the same commit.
* **Demonstrate a gate failing before trusting it passing.** Every new checker here was
  perturbed and observed going red: `map_signs --selftest` (two ways),
  `dungeon_spawn_check` (formula perturbed), `strings_atlas --selftest` (failed for real,
  twice, during development).
* **`pgrep`/`pkill -f` matches its own shell.** Kill by pid, or check ports.
* **Scratch goes to `/var/tmp`, never `/tmp`** (tmpfs here — it takes RAM from the model).
  Note `ctx_execute_file` resolves the workspace root differently and will refuse paths
  under `/var/home/...` for some files; use a script file for binary work.
* **Probe maps must be installed before launch** (`spice86_start.sh --seed-map`).
* **The world wraps.** Start probe walks mid-map.
* **Enumerate `captures/spice86/` before running a new capture.** Today this saved a
  launch: the dungeon formula was checkable against two dumps already on disk.
* **Read the tool index in `docs/spice86-capture.md` before writing anything against a
  live session.**
* **`[DI+0x1B7]` is a kind index on the overworld and `slot>>1` in a dungeon.** Neither is
  a sprite. Trust the live dump, and read the spawner before naming a field.
* **A single area is not a sample.** Still true, and today it gained a variant: **a single
  agreeing sample is not a test either.** 776 agreeing cells could not answer which field
  the renderer reads; one disagreement did.
* **A capture directory name is not a fact about its contents.** `airport32` is a dungeon;
  `tower-34` is a tower. Classify by bytes, and `tools/dungeon_spawn_check.py` now does.
* **An "active slot" filter is a claim about the encoding.** NEW: so is a *scoring* filter.
  `monx_layout_scan` initially scored slots the file never authored and reported sector 20
  as a total layout failure when the file simply authors nothing. Absence and
  contradiction are different verdicts.
* **Do not upgrade an arithmetic fit into a mechanism.** NEW corollary: do not upgrade an
  idiom name into branch polarity. `cmc;sbb;das;cmc` ends with a complement that inverts
  the carry, so the following `jb` is the **success** path. Simulate it.
* **`view.h`'s two-step is not a bug.** NEW: and the open question was never the shift, it
  was the field. It reads the grid cell. See `docs/art-index.md`.
* **NEW — a shop needs an NPC standing at the sign.** `T` alone, or `T` with a stale
  direction buffer, prints `TRANSACT-PASS` and means nothing. Use
  `--keys T,Up --delay 0.02`, launch with `--patch-arrows`, and check
  `tools/shop_access.py` for where it is even possible.
* **NEW — the shop closes after one purchase.** A second item's keystrokes fall through to
  the command loop, where `3` is an illegal command and `y` is YELL. Re-open per item.
* **NEW — `u2_edit.py maxout` does not populate the armour table.** It sets `DS:62` to
  POWER while `DS:96+6` stays `00`. Either owned ≠ worn or the seeder is incomplete;
  unresolved, and it affects any capture that assumes a kitted character is fully kitted.
