## 2. What this session actually changed

16 commits. Grouped, newest first.

### The forced-keep queue: 36 outstanding → 0

`python3 tools/forced_keep_audit.py --queue` prints the queue (new mode; before this it
printed a census of *causes*, which never moved, and a reader could not tell finished work
from unfinished). 47 files now carry a `# body corrected: 2026-10-28e` marker. Body lines
26,045 → 25,748.

What the corrections were, in every case: **the map boundary cut an instruction in half, and
the next fragment decoded the tail bytes as code.** The fix is uniform — the tail becomes a
`.byte` line naming where its instruction started — and it is byte-neutral, so
`assemble_clean.sh` stays green by construction and `check_func` proves each span anyway.

Three of the last five items were **not defects**:

- `asm/6DFD` and `asm/4050_cmd_T` were the audit's own walk desynchronising on a merged file
  and reporting a forced-keep one byte late. Fixed in the tool, not in `asm/`.
- `asm/5287` and `asm/0720` were **data islands misfiled as routines**. Both were settled by
  the same kind of evidence: a call or jump target is an instruction boundary, so a claim that
  an instruction straddles into one is impossible on its face. `asm/52CA` is entered by
  `call L_0054ca` from six places and `asm/0764` by `call`/`jmp` from two, which refuted the
  `lock add %bl,-0x7d(%bp,%di)` and the `push $0xe845` readings that had been holding those
  spans open. Both spans are now `ret` + a `db` table, renamed `*_data_mixed.asm`, in the
  style the tree already uses for 47BD/4815/486D.

Families that came out of it:

- **The `ANOS:` era table is now fully visible.** Five entries of
  `call str_out / db text / jmp dispatcher` with no padding, whose boundaries the map had cut
  in three places. Three of the five era lines had been invisible to `asm/`, and
  `asm/3596_show_year_1990` was named for the second-to-last thing inside its own range.
- **The creature-slot sweep** (`mov $0x0,%bh / mov 0x1f,%bl / mov %bx,%di /
  mov 0xNN(%di),%al / call`) recurs through the 46xx–48xx range and was cut in eight places.
  The bad decodes had put a `gs` prefix, a `data32` prefix, an `arpl`, a `bound`, a `xlat` and
  an `outsb` into a listing of a binary that executes none of them.
- **`asm/50F9`, the status-line printer**, was inventing four `call`s to two routines
  (`0x55df`, `0x53a5`) that it does not call. `c0` always takes an imm8 and `bc` always takes
  an imm16, so the instructions could not end where the boundaries said; the bytes the
  boundaries cut on were immediates.

### Three documented dispositions were wrong, and are now retracted

- **`asm/2395` and `asm/35DD` were recorded as single-byte NOP-padding seeds** in
  `disasm/defects.md`, `disasm/phase2-summary.md` and two `asm/` headers, with a follow-up
  proposing `kind=nop-pad` in the map. They are the operand byte of `out %al,$0x90` and of
  `aam $0x90`. Reko failed because a one-byte tail is not a procedure — a fact about the
  boundary, not about the byte. The follow-up is dropped: a `kind=nop-pad` would have written
  a wrong reading into the one artefact meant to be the tiling of truth.
- **`asm/5287` and `asm/0720` were recorded as routines** (`sub_5287`, `sub_0720`, evidence
  `seed+reko`) while their entire bodies were forced-keeps decoding as `lock aas`, `ud0`,
  `int1`, `fdivl (%bx)` and `(bad)`. Both are a `ret` followed by a data table: 5288's address
  is taken by `lea %cs:0x5288,%cx` at asm/527F and walked by asm/4C1E, and 0720 is the landing
  pad of `dec %bx ; js L_000920` at asm/0715. Renamed to `*_data_mixed.asm`.
- **Most `gas re-encodes 'X' differently` markers on a truncated instruction are false.**
  `--verify-markers` re-asks gas at the real address in `check_func`'s own context: of 59
  gas-worded partial keeps, **48 gas encodes byte-for-byte**, 10 genuinely differ (the
  register-to-register moves — `mov %di,%bx` is `8b df` in the binary, gas emits `89 fb`), 1
  does not assemble. The tool blamed the assembler for its own truncation. This is why the
  queue no longer groups by marker wording: the two wordings were one kind of fix.

## 3. Facts worth knowing cold

- **A partial forced-keep is a boundary, never a gas limitation.** If fewer bytes were kept
  than the instruction needs, gas was never given a chance. `--verify-markers` is the tool that
  says so per site.
- **A call or jump target is an instruction boundary, and that is a proof you can use.** Two of
  the last queue items claimed an instruction straddling into `asm/52CA` and `asm/0764`; both
  are entered from two to six places, so the claim was impossible without touching a byte.
  Grep for `call L_`/`jmp L_` to a fragment's own label before believing a truncation at its
  left edge.
- **Slot 15 of the speed table is not a table entry.** `asm/5F08` computes a value with the same
  `mulw 0x74 ; divw 0x554` scaling `asm/06ED` uses, guards it with `cmpw $0x1800,0x74`, divides
  by 5000, stores it into `DS:580+0x1e`, and then calls the lookup. The measured 7 is a
  snapshot, not a constant.
- **A byte histogram is a cheap classifier.** `asm/72A0` was diagnosed in one line of code by
  counting zeros (56%), and `asm/5D58` and the two corrected islands all had a long NUL run.
  Before decoding a suspicious span, count its zeros.
- **gas encodes these exactly** (measured, not assumed): `movb $0x3,0x2f`, `mov 0x61,%al`,
  `mov %al,0x28`, `mov $0x0,%bh`, `mov $0x1,%bl`, `aam $0x90`, `out %al,$0x90`, `clc`,
  `adc $0x13,%al`, `movb 0x4a,%al`. **gas does not** encode `mov %di,%bx` (`8b df` vs `89 fb`)
  or `mov 0x76(%di),%al` (it shortens the displacement to `8a 45 76`). Test before believing
  either way; the marker text is not evidence.
- **`db` has three shapes in this tree**: `db "ORIGIN",0x00`, `db 0x8d,"KILLED--GOLD+",0x00`
  and pure numeric runs. A parser that matches only the first silently walks numeric data as
  code — which is what the audit did.
- **Labels are body.** When re-cutting a merged span, keep every `sub_xxxx:` and `L_xxxxxx:`
  line and merge only the `.byte` lines. That is what made `asm/50F9` pass CP0 unchanged in
  its label set.
- **`str_out_audit --emit` prints a status line to stdout and writes the file itself.** Never
  redirect its stdout into the TSV; that wrote the status line into the file and the next
  `--check` crashed on it.
- **Never put backticks in a `git commit -m` string.** The shell runs them. Twice this session
  the message came out with holes where the mnemonics were. Use `-F` with a file, or `-F -` with
  a quoted heredoc.

## 7. Hazards. Each of these cost minutes.

1. **A control that can only pass while the defect exists is a second copy of the defect.**
   `strings_atlas` required its fallback source to contribute rows; fixing the last gap made
   the harness report itself broken for succeeding. Assert the mechanism, not the symptom.
2. **A tool's error text describes what it tried to do, not what went wrong.** Grouping the
   queue by the forced-keep marker wording would have planned two kinds of fix where there is
   one. Re-derive the cause from the bytes and make the re-derivation a mode of the tool.
3. **A verification script's exit status is part of its output.** `[ $fail -eq 0 ] && echo PASS
   || echo FAIL` exits 0 either way, because `echo` always succeeds.
4. **A hardcoded absolute path in a check script is a gate that tests the wrong tree.** It
   passed locally and would have checked nothing on a runner.
5. **A linear objdump pass desynchronises on inline data**, and a two-byte drift is enough to
   invent an instruction straddling a real boundary. Consume the asm's own `db`/`.byte` lines;
   re-decode locally where the map has no entry.
6. **The first version of a classifier is usually wrong about its own categories.** The
   `gas re-encode` vs `stop-trunc` split looked like two fix shapes; it was one shape with two
   wordings, and the detector had also been blind to all 28 `stop-trunc` markers because it
   matched on the phrase `re-encodes`.
7. **Compute instruction targets in code.** `e8 eb 17` at runtime 37F1 is a call to `str_out`
   only in *file* space; computed in runtime space it points at a non-printer and the whole
   reading looks wrong. Labels in this tree are file offsets.
8. **`--emit` that both writes a file and prints to stdout will corrupt the file if you
   redirect.** `str_out_audit.py --emit` is the one here.
9. **Backticks in `git commit -m` execute.** Use `-F`.
10. **Negative claims need the right pattern.** Still true; nothing this session re-derived a
    negative, but the `lock`-prefix question in § 5 is exactly where a plausible negative would
    be asserted by mistake.
11. **Scratch goes in `/var/tmp`, never `/tmp`** (tmpfs, i.e. RAM taken from the model).
