## 2. The one thing to do first

**Identify what `238b → 0x1240` is.** That jump is the contact path: `2201`/`220a` compare a
creature's candidate cell against the player's `DS:00/DS:01`, and on equality branch to
`238b`, which tests `DS:4A` and jumps to `0x1240`. If that is the attack, CP5 W6 can be
written against the real trigger instead of an inferred one.

**Why it is awkward:** no `asm/` file begins in `0x1230..0x1250`, so `0x1240` sits inside
another fragment's span. Grep-by-filename will not find it. Walk the fragment that covers it.

Second, and cheap: **test the retreat loop live.** Damage an Orc to ≤ 15 HP and watch for
`+1` HP per turn and a direction reversal. The threshold `cmp al,0x10` is proven to exist,
but that the *low* branch is retreat rather than something else is still inference from a
wiki, not from the bytes. A polarity misreading of that `jae` would be invisible statically.

## 3. Proven this session — use these, do not re-derive them

**Combat arithmetic**
- Damage: `(8 * readied_weapon + strength_byte) >> 2`. **There is no weapon-power table** —
  the readied-weapon index is the multiplicand (`add al,al` ×3).
- Hit: `(rand >> 1) < agility_byte`. Max roll 127, so a displayed agility of **80** is byte
  `0x80` = 128 and **guarantees a hit**. Independent third-party corroboration of the BCD
  reading.
- Kill reward: `gold += (rand & 0x17) | 1`, `exp += rand & 0x07`, both BCD.
- Food: **19** per accepted move, **10** per pass.

**The creature turn routine — `0x2122..0x2260`** (`docs/monster-spawn.md` § 12)
- `2122` `cmp al,0x10` on `mon_hp`; `212A` `incb` → **regeneration +1/turn below 16 HP**.
- Move is `adc al,[DS:19]` / `adc al,[DS:1A]` with an `and 0x3f` torus mask.
- **`DS:19/1A` is the pursuit vector**: `asm/152E` sets it to `player − creature`;
  `asm/0B0F` negates it in place. Toward = pursue, negated = retreat.
- `2199` writes `DS:1F`; `21a6..21d8` gate on it against a ladder
  (`0x5c, 0x10, 4, 0, 0x14, 0x70`); `23fc` returns `0xFF` = refuse, `23f7` returns `0` = accept.
- `2216`/`2233` are the **commit half of the move** (staging `DS:27/28` → `mon_x/mon_y`).
  § 11's "placement API" is this, not a separate spawner.
- Species-specific movement: `21a6` special-cases `0x2c` (Sea Monster) and `0x48` (Frigate).

**Movement geometry, measured live** (`captures/spice86/cp5-g28-approach/`)
- **Orc 190/190 diagonal, Fighter 164/164 diagonal, Merchant 123/124 axis.** Movement
  geometry is per-species. W6 cannot be a plain 4-neighbour step-toward.

**Save format**
- `file[i] == DS[0x36+i]`. `DS:36` is the **first byte of the character name** — that single
  byte is the whole "is there a game yet?" test (`asm/5400: cmp byte [0x36],0`). **There is
  no default game state**; a new game is the absence of one.
- `DS:49/4A` = sector digits, `DS:5A/5B` = entry x/y. Poking these in a copy places the
  player anywhere in any sector — the fastest way to set up a capture.

**Address model** — `linear = file_offset + 0x17D0`. Verified by disassembly. The
`L_000ec0` label numbering is **not** an address space (`0x17D:0xEC0` is string data).

## 4. Traps already paid for — do not pay twice

1. **`DS:1F` is not a slot cursor.** It read **120** live. I called it a slot cursor and then
   "general scratch" on the same day; both were wrong. It feeds the `21a6` rate ladder.
2. **`MEMORY_WRITE` breakpoints on computed addresses do not fire usefully.** The effective
   address is `DS:137 + DS:1F`, which moves. Use `CPU_EXECUTION_ADDRESS` on code.
3. **`turn_recorder.py` produced zero turns in two runs** — its food-odometer trigger never
   fired. Working loggers are in `captures/spice86/cp5-g27-wilderness/g27_log.py` and
   `g27_stat.py` (one key, one snapshot).
4. **Generating turns requires accepted moves.** The auto-pass is ~7.5 s of wall clock.
   Alternating `Left,Right` is two accepted moves with zero net displacement — the cheap
   way to burn hundreds of turns while holding the player still.
5. **A player walking past a creature makes it register as "fleeing".** My first pursuit
   measurement did exactly that and reported Orcs retreating. Hold the player still.
6. **Creatures take 2-cell steps**, so a step can net zero Manhattan change. Any per-step
   "toward/away" metric must account for that, or it measures geometry, not intent.
7. **Random-walk baseline for Manhattan distance is 50%, not 33%.**
8. **Read a span, not a fragment.** Three wrong conclusions today came from reading
   bulk-wave fragments individually. Concatenate by address order first.

## 7. Working recipes

```bash
# headless run with a seeded save, detached
setsid nohup tools/spice86_start.sh --headless --patch-arrows \
  --player /var/tmp/u2/saves/PLAYER --auto-play --name LABEL \
  --http-port 20180 --mcp-port 20181 > /var/tmp/u2/x.log 2>&1 < /dev/null & disown

# read DS (physical = 0x08BE*16)
curl -s "http://127.0.0.1:20180/api/memory/$((0x08BE*16))/range/768"

# stop — always via the script
tools/spice86_stop.sh
```

MCP `local-mcp` tools that worked: `read_disassembly`, `read_cpu_state`, `add_breakpoint`
(`CPU_EXECUTION_ADDRESS`), `search_memory`, `write_memory`, `step`/`step_over`.
`search_memory` on a short fragment beats a long hand-assembled pattern — common idioms like
`mov bl,[0x1f] / mov di,bx` appear eight-plus times.

**Verification bar for any commit touching engine or asm:**
`bash tools/assemble_clean.sh` (must print 37344 bytes identical) and
`make -C engine test` (CP0..CP5 green). Docs-only commits skip the suite per AGENTS.md.
